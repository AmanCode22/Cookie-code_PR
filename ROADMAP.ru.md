## Готово

- [x] Базовый каркас: окно Electron + инъекция оверлея
- [x] Система вызовов инструментов: read / write / edit / glob / grep / bash и т.д.
- [x] Инициализация проекта: выбор каталога + дерево + системный промпт
- [x] Мультиоконность: независимый профиль на каждое окно
- [x] Поддержка MCP: конфиг + SDK + UI-панель + инструмент `mcpCall`
- [x] Скиллы: загрузка и выполнение пользовательских скиллов
- [x] Настраиваемый UI: 27 обоев, слайдеры блюра и прозрачности
- [x] Инлайн tool-блоки (раскрывающиеся, с подсветкой ошибок)
- [x] Бейдж мета-информации (⏱ время · ~токены)
- [x] RGB-анимация ника
- [x] Вкладка настроек внутри нативной модалки DeepSeek

## Следующее (по приоритету)

### 1. Надёжность

**Цель:** уменьшить прерывания и улучшить UX.

- [ ] Прерывание генерации
- [ ] Автоматический retry при сетевых сбоях
- [ ] Подсказка «ручной парсинг» при ошибке инструмента

**Критерий:** пользователь может прервать генерацию; кратковременные сетевые сбои восстанавливаются автоматически; ошибки инструментов дают чёткую подсказку о ручном парсинге.

---

### 2. UX вызовов инструментов

**Цель:** сделать агентный цикл более прозрачным.

- [ ] Просмотр полного вывода каждого инструмента в отдельной панели
- [ ] Копирование / повторный запуск отдельных tool-блоков
- [ ] Инлайн diff-превью для `edit`-вызовов

**Критерий:** каждый tool-блок даёт доступ к сырому выводу, копированию и повторному запуску.

---

### 3. Новые возможности

**Цель:** расширение агента.

- [ ] Субагенты
- [ ] Сжатие длинных диалогов

**Критерий:** определяется после первых реальных сценариев использования.
